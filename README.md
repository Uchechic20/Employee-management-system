

Overview

A Python-based Employee Management System developed using Object-Oriented Programming (OOP) principles. This project allows users to manage employee records efficiently while demonstrating concepts such as abstraction, inheritance, custom exception handling, data validation, and JSON-based data storage.

Features

- Add new employees
- View employee records
- Update employee information
- Delete employee records
- Search for employees
- JSON data persistence
- Custom exception handling
- Input validation for:
  - Salary
  - Age
  - Gender
  - Mobile Number
  - Bank Account Number

Technologies Used

- Python
- Pandas
- JSON
- Object-Oriented Programming (OOP)

Concepts Demonstrated

- Classes and Objects
- Inheritance
- Abstraction
- Polymorphism
- Custom Exceptions
- File Handling
- Data Validation

Future Improvements

- SQLAlchemy Integration
- PostgreSQL Database Support
- REST API Development with FastAPI
- Authentication and Authorization
- Web-based User Interface
